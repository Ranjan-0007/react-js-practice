# React CSS Modules Practice

This project is created to **practice and demonstrate the use of CSS Modules in React**.  
It focuses on **scoped styling**, **component-level CSS**, and **clean project structure**.

---

## 🎯 Purpose of This Project

- Practice **CSS Modules** in React
- Understand how styles are scoped to components
- Avoid global CSS conflicts
- Write clean and maintainable component styles
